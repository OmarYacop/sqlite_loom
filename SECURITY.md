# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| 0.1.x and earlier | No |

Only the latest patch release in the supported minor series receives security
fixes.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/OmarYacop/sqlite_loom/security/advisories/new).

Do not disclose vulnerability details in a public issue.

Include the affected versions, reproduction steps, expected impact, and any
proposed remediation. You should receive an acknowledgment within three
business days. Confirmed vulnerabilities will be coordinated privately until a
fix and advisory are ready.
