# Architecture decision records

Architecture decision records (ADRs) explain choices that are expensive to reverse. Accepted ADRs
are durable context for maintainers and AI agents; they do not replace public API documentation.

Copy `0000-template.md`, use the next four-digit number, and keep the decision focused. Status is
one of **Proposed**, **Accepted**, **Superseded**, or **Rejected**. A superseded ADR remains in the
tree and links to its replacement.
